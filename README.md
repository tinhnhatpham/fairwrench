# FairWrench — AI Mechanic Quote Auditor & Free NHTSA Recall Shield

Upload a photo or paste a mechanic's repair estimate to catch overpriced labor, dealer upsell traps, and free open NHTSA recalls in 15 seconds.

## Local Preview
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).
